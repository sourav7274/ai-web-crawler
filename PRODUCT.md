# PageBrief
A public assignment app that turns one public HTML webpage into an English overview and 3–5 key points using the Gemini free tier. Audience: reviewers and readers wanting a quick understanding of an article.
Next.js frontend and Node.js API live in one project on Vercel. No accounts, database, saved history, browser rendering, or bot-protection bypass. API credentials remain server-side. AI output must be grounded in scraped text.
The user selected a polished, light, vertical reading flow: URL form first, summary beneath it. Loading, recovery, mobile layout, accessible controls, and copy are required.
